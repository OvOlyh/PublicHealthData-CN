# 公共卫生与健康数据资源指南
本 Wiki 是一份面向公共卫生学习与研究的中文数据资源指南，按疾病与健康、卫生服务、人群健康三个主题组织。你可以按研究问题查找数据来源，再到资源条目了解覆盖范围、获取方式、适用场景和使用限制。
[浏览 Wiki 首页](https://github.com/OvOlyh/PublicHealthData-CN/wiki)

Isma 编写了疾病与健康的三个资源条目，并补充了 WHO GHO 指标检索与 API 查询的实践指南。淡水鱼编写了卫生服务专题导航及 OECD Health 条目，并在专题导航中整理了 World Bank HNP 和 Medicare Data 的选用说明及建议实践路径。OctopusKiss 编写了人群健康的三个资源条目，分别记录了 UNICEF Data 的主题与国家查询、NHANES 调查数据及配套文档的获取方式，以及 HealthData.gov 的检索、来源核对和 CSV 下载过程。

Wiki 首页由三人共同维护，现阶段由 Isma 负责整体汇总，将各专题的资源入口和选用说明整合到首页。

## 交叉审阅与持续维护

条目作者先自查来源、指标、覆盖范围、访问条件和页面链接。审阅者再沿条目所列路径复现至少一项关键操作，例如查询指标或导出数据。发现问题时，审阅者在 GitHub Issues 中记录涉及页面、问题描述、核查依据和修改建议。条目作者修订页面，并在维护记录中注明改动和关联 Issue。按项目规范，审阅者复核通过后关闭 Issue。每位成员也按月检查自己负责的资源，及时更新链接、数据版本、下载入口和使用条件。[资源收录与审核规范](https://github.com/OvOlyh/PublicHealthData-CN/wiki/%E8%B5%84%E6%BA%90%E6%94%B6%E5%BD%95%E4%B8%8E%E5%AE%A1%E6%A0%B8%E8%A7%84%E8%8C%83)

在已完成的一次审阅中，Isma 发现 UNICEF Data、NHANES 和 HealthData.gov 三个条目的相关资源链接无法跳转到正确页面，并将问题、修改建议和验收标准记录在 Issue #1。OctopusKiss 修正了链接，在 Issue 中反馈处理结果，并将该 Issue 标记为已完成。[Issue #1 修订记录](https://github.com/OvOlyh/PublicHealthData-CN/issues/1)
